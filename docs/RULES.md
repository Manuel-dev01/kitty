## Eligibility gates

- [ ] **Team of 2–4.** "Individual participation is not allowed ❌ Teams up to 2-4 people max ✅".

- [ ] **Register for the StacStart Summit:** "You must register for the StacStart Summit to be eligible" → https://luma.com/2obyd8e4

- [ ] Announce participation on social media with **#BuildWithStacStart**
- [ ] Based in Nigeria, Kenya, Uganda or Ghana

## Open questions: ask in the hub / info@stacstart.com

1. Pre-existing code policy. The FAQ lists it without an answer. (Kitty starts from a fresh repo, so we're safe either way.)
2. Where is the submission portal, and is there a video length limit?
3. Finale format: live pitch length, and whether a live demo is expected or the video is played.

## Submission (all required)

- [ ] **Working prototype:** "a live, deployed URL or accessible application"
- [ ] **Codebase:** "a public GitHub repository link"
- [ ] **Video pitch:** "a video demo showcasing your build and features"
- [ ] **Project details:** title, target audience, tech stack used

## Final checklist before pressing submit

- [ ] Open the live URL in a **logged-out, incognito** browser on a phone and on a laptop
- [ ] Judge mode "Run a round" succeeds (live, or replay with badges visible)
- [ ] Repo is public, README renders, no secrets in history (`git log -p | grep -i -E "sk_|secret|key"`)
- [ ] Video is public/unlisted and plays logged-out
- [ ] Target audience line: "Members of savings circles (ajo, susu, chama) spread across Nigeria, Kenya, Uganda and Ghana, and the organisers who run them"
- [ ] Track: FinTech & Commerce
- [ ] Every teammate is named in the submission
